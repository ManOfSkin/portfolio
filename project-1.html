ReSource

Application web moderne développée dans le cadre du Projet CUBE au CESI. Elle combine un backend PHP avec une interface frontend riche et réactive basée sur Vue.js.

Aperçu du projet

L'application ReSource est construite sur une architecture structurée qui sépare rigoureusement le code source, la configuration globale et les ressources publiques. Côté client, l'interface utilisateur s'appuie sur des composants Vue.js réutilisables, incluant des vues spécifiques pour la gestion des formulaires et des interfaces d'authentification.

Pour garantir une expérience optimale sur tous les supports, les en-têtes et pieds de page disposent de composants dédiés aux formats bureau et mobile. Le design intègre la typographie officielle Marianne et utilise le préprocesseur SCSS pour le style. Le backend repose sur PHP-Symfony et gère la base de données via Doctrine. L'intégrité et l'évolution du schéma de la base de données sont assurées par des scripts de migration. Enfin, l'ensemble des ressources frontend est compilé et optimisé à l'aide de Webpack Encore et Node.js.
