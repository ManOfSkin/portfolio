Un outil conçu pour optimiser les flux de travail, la collaboration et la gestion de projets de manière intuitive.

Voir le code

Aperçu du projet

Le projet Flowboard a été réalisé en équipe à la fin de ma formation intensive au sein du bootcamp Le Wagon. L'objectif de ce projet final était de concevoir, développer et déployer une application web complète en un temps record (deux semaines), en partant de l'idéation jusqu'à la mise en production.

Cette expérience m'a permis de mettre en pratique et de consolider mes compétences en développement fullstack. Nous avons travaillé sur l'architecture de la base de données, la logique métier côté backend, ainsi que la création d'une interface utilisateur dynamique et responsive. Ce projet a également été l'occasion d'éprouver les méthodes de travail collaboratif utilisant Git, GitHub et les revues de code (Pull Requests).
